# Divvy Bike Analysis

## Project Overview
This project analyzes Divvy bike-sharing data to understand how different types of riders use the service.

## Project Goal
The goal of this analysis is to understand how annual members and casual riders use Divvy bikes differently.

## Tools
- Excel
- SQL (BigQuery)
- Tableau
- R

## Key Findings
- Annual members take more rides than casual riders.
- Casual riders take longer rides on average.
- Casual riders are more active on weekends.

## Recommendations
- Increase awareness of membership benefits.
- Offer promotions to encourage casual riders to become members.
- Focus marketing campaigns on weekends.
